# Spring Boot Learning

🚀 Repositório dedicado aos meus estudos de Spring Boot e desenvolvimento Back-End com Java.

Aqui organizo os conteúdos que estou aprendendo através de cursos, documentações, vídeos e projetos práticos. O objetivo é registrar minha evolução no ecossistema Spring e consolidar conhecimentos fundamentais para o desenvolvimento de APIs REST.

## O que você encontrará neste repositório

- Spring Boot
- Spring Web
- JPA e Hibernate
- Spring Data JPA
- Validações
- Tratamento de exceções
- Spring Security
- JWT
- Banco de Dados
- Testes
- Boas práticas de desenvolvimento

## Objetivo

Este repositório funciona como meu ambiente de aprendizado contínuo.

Cada pasta representa um assunto, curso ou conceito estudado durante minha jornada com Spring Boot. Conforme avanço nos estudos, novos conteúdos serão adicionados e organizados aqui.
